# Dark Mode Toggle

## Description

Add a dark/light mode switch that persists the user's preference in localStorage.

## Acceptance criteria

- [ ] The user can switch between dark and light mode from a visible control.
- [ ] The whole app changes to the chosen mode as soon as it's selected.
- [ ] The chosen mode is still applied after a page reload.
- [ ] The control shows which mode is currently active.
